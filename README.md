# Decoding Molecular Instability: Transcriptional Noise in the Context of Alzheimer’s Disease Progression.

Reproducible Snakemake pipeline for single-cell RNA-seq analysis integrating VarID2, Scallop, and Decibell. It automates preprocessing, variability analysis, and differential expression using public datasets. The workflow is modular, scalable, and ensures full reproducibility from raw data to final results.
